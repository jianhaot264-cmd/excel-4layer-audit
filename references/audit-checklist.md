| 检查项 | PASS | FAIL | WARN |

| zip 完整性 | `testzip()` 返回 None | 有损坏成员 | — |

| 函数版本兼容性 | 无独占函数 | 命中黑名单函数 | — |
| 错误值扫描 | 0 处 | > 0 处 | — |

| 新增工作表 | 有新表 | — | 无新表（可能改在原表上，需人工确认） |

## 三、独立重算脚本模板

按需改 `EXPECT` 与解析部分即可。核心纪律：**从数据源读原始数据，按名称查表比对。**

```python
# -*- coding: utf-8 -*-
"""独立重算：脱离表格引擎，从数据源用纯 Python 重新推导并逐格比对"""
import openpyxl
from collections import defaultdict

DELIV = r"成品.xlsx"
wb = openpyxl.load_workbook(DELIV, data_only=True)     # data_only=True 拿缓存计算值

# ---- 1. 从数据源读原始记录（不要读答案区） ----
ws = wb["数据源"]
data = [r for r in ws.iter_rows(min_row=2, values_only=True) if r[0] is not None]

# ---- 2. 独立重算 ----
group_amt = defaultdict(float)
group_days = defaultdict(set)
days = {r[0] for r in data}                            # 统计天数 / distinct 分组
for dt, grp, qty, price in data:
    group_amt[grp] += qty * price
    group_days[grp].add(dt)

expect_rank = sorted(group_amt.items(), key=lambda x: -x[1])

# ---- 3. 逐格比对（按名称查表，不要按下标对齐） ----
TOL = 0.005
bad = []
ans = wb["作答区"]
for r in range(7, 17):
    name = ans.cell(r, 1).value
    got_amt = ans.cell(r, 2).value
    got_days = ans.cell(r, 3).value
    if abs(got_amt - group_amt[name]) > TOL:                    # 金额必须精确对应
        bad.append((name, "金额", got_amt, group_amt[name]))
    if got_days != len(group_days[name]):                       # 去重计数必须一致
        bad.append((name, "有效天数", got_days, len(group_days[name])))
    exp_rank_no = 1 + sum(1 for v in group_amt.values() if v > group_amt[name] + 1e-9)
    if ans.cell(r, 5).value != exp_rank_no:
        bad.append((name, "排名", ans.cell(r, 5).value, exp_rank_no))

print("不一致项:", bad if bad else "无 —— 全部通过")
```

**结论区（跨表引用）也要单独核对**：它引用的是明细区的坐标，最容易出现"引用串行一格"——表现是数字都对但对应错了品牌。做法是把结论区与 `expect_rank` 逐位比对。

## 五、文档类（docx）附加清单

当交付物是 Word/WPS 文档（尤其含表格公式、域、目录、页码引用）时，追加：

- [ ] `verify_docx.py --list-engines` 探明 Word / WPS 文字是否都可用
- [ ] 两引擎各自 `Fields.Update()` 后，**域结果逐项一致**
- [ ] 两引擎的 段落 / 表格单元格 逐项一致
- [ ] **有效性自检**：把某个域缓存故意写成错值，确认引擎能算回正确值（否则等于没重算）
- [ ] 与期望值清单（`para:N` / `table:T:R:C` / `field:N`）全部命中
- [ ] 读完文档后重算文件哈希，确认 `SaveChanges=0` 生效、文件未被写回

> 注意 `Document.Fields` 已包含表格内的域，不要重复遍历（见 pitfalls P15）；
> Word 没有 `Calculate`，重算靠 `Fields.Update()`（见 P16）。
